# Kotwica

Prototyp aplikacji webowej (mobile-first) wspierającej zdrowe nawyki snu — działa w 100% lokalnie w przeglądarce.

Pełna specyfikacja: [DESIGN_AND_ARCHITECTURE.md](./DESIGN_AND_ARCHITECTURE.md) (**v2.0** — 6 profili + ścieżka bezpieczeństwa).

## Uruchomienie

```bash
npm install
npm run dev
```

Otwórz [http://localhost:5173](http://localhost:5173). Na desktopie aplikacja wyświetla się w korycie ~430px (rama telefonu można włączyć w **Ja → Wygląd**).
